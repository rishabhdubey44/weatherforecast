# Weather Forecast App

A web-based weather application built using Python and Flask that provides weather information through a simple user interface.

## Overview

The application uses Flask as the backend framework and HTML/CSS for the frontend. Users can interact with the application to retrieve weather information.

## Features

* Weather search
* Flask-based backend
* Web-based user interface
* Dynamic weather information
* Separate frontend templates and static files

## Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript

## Project Structure

text
weatherforecast/
├── app.py
├── templates/
└── static/

## How to Run

1. Clone or download the repository.
2. Install Python.
3. Install Flask and the required dependencies.
4. Run the Flask application.
5. Open the local server URL in your browser.

## Purpose

This project was created to practice Python, Flask, web development, and connecting a backend application with a web interface.
